## RE01 — Retrieval practice

| Field | Value |
|---|---|
| CLAIM | Practice testing can improve later achievement compared with comparison study conditions. |
| SOURCE | [Yang et al., Testing boosts classroom learning](https://pubmed.ncbi.nlm.nih.gov/33683913/); author abstract/metadata. |
| PUBLICATION TYPE | Peer-reviewed systematic review/meta-analysis. |
| YEAR | 2021. |
| POPULATION | Students in 222 classroom studies; mixed ages, subjects and settings. |
| TASK/DOMAIN | Classroom quizzing and achievement tests. |
| METHOD | Synthesis of testing versus comparison conditions; moderator analysis. |
| EFFECT/RESULT | Overall positive average; format, feedback and study design moderate results. No Mingo effect estimated. |
| LIMITATION | Achievement outcomes and comparison conditions vary; not a trial of this feed. |
| TRANSFERABILITY TO MINGO | Supports retrieval opportunities, not a fixed quiz count or universal gain. |
| PRODUCT IMPLICATION | Keep independent first response and later checks distinguishable. |
| MINGO HYPOTHESIS | Objective-aligned retrieval improves delayed performance without excessive friction. |
| VALIDATION NEEDED | Content-valid parallel items, delayed checks and later adequately powered comparison. |

## RE02 — Spacing in second-language learning

| Field | Value |
|---|---|
| CLAIM | Spaced L2 practice supports learning; spacing choices depend on retention interval. |
| SOURCE | [Kim and Webb](https://onlinelibrary.wiley.com/doi/abs/10.1111/lang.12479); publisher abstract. |
| PUBLICATION TYPE | Peer-reviewed meta-analysis. |
| YEAR | 2022. |
| POPULATION | 3,411 learners across 48 experiments. |
| TASK/DOMAIN | L2 targets, immediate/delayed posttests. |
| METHOD | Spaced/massed, longer/shorter and equal/expanding spacing comparisons. |
| EFFECT/RESULT | Spacing favored learning overall; longer spacing favored delayed rather than immediate tests; equal/expanding schedules were similar on average. |
| LIMITATION | Tasks, feedback and delays differ; no universal schedule. |
| TRANSFERABILITY TO MINGO | Relevant mechanism, local scheduler parameters unvalidated. |
| PRODUCT IMPLICATION | Explain due review; record actual delay and available evidence. |
| MINGO HYPOTHESIS | A bounded due review helps later independent retrieval. |
| VALIDATION NEEDED | Delayed objective-level evidence, burden and adherence across circumstances. |

## How to use this register

RE01–RE15 and RE20 support learning-design hypotheses, not a final curriculum. RE16–RE19 and RE21–RE28 guide measurement/engineering safeguards, not human acceptance. RE29–RE30 bound external research. [Learning model](LEARNING_EXPERIENCE_MODEL.md), [adaptation principles](ADAPTATION_PRINCIPLES.md), [content rubric](CONTENT_QUALITY_RUBRIC.md), [measurement framework](MINGO_PRODUCT_MEASUREMENT_FRAMEWORK.md) and [purpose register](TELEMETRY_PURPOSE_REGISTER.md) turn these into reviewable specifications. Preserve dissenting findings and source access limitations. Refresh a source when a decision depends on changed guidance; do not promote a hypothesis by repeating it across files.

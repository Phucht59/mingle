# Content quality rubric V2 — content review PENDING

Updated 2026-10-02. Canonical equivalent of the requested **CONTENT_QUALITY_RUBRIC_V2.md**; this existing filename is retained to avoid duplicate truth and broken references. UI fixture checks demonstrate a workflow, not real reviewer authority or valid curriculum. This rubric does not add a backend/schema rule, final level framework or production publishing implementation. Phase 3 HOLD.

Use **evidence-centered design**: **CLAIM → TASK → EVIDENCE → SUPPORT → RETRIEVAL → TRANSFER → DELAYED CHECK**. The [ETS research framework](https://www.ets.org/research/policy_research_reports/publications/report/2003/hsgs.html) informs this argument structure; it does not validate Mingo items. Relevant external evidence, limitations and local hypotheses: [RE01–RE08 and RE20](MINGO_RESEARCH_EVIDENCE_REGISTER.md).

Review before a revision is considered publishable: **0 = missing/blocking; 1 = needs correction; 2 = ready with inspectable evidence**. No average can compensate for a blocking criterion. Record author, independent content/linguistic reviewer, exact draft/revision ID, reviewed evidence, score per criterion and correction rationale. Human/content-expert review is PENDING; no author or AI auto-signs it.

| Criterion | Required evidence / rejection condition |
|---|---|
| Objective | One observable action in a specified target-language/task context; reject vague “learn English.” Level labels remain provisional until their content framework is approved |
| Claim | State what a correct response would support, its scope and what it would not support. A recognition item must not claim spontaneous speaking competence |
| Task | Prompt, required response, conditions, correct answer/rubric and plausible distractors align with the objective. Reject tasks whose wording gives away the answer or tests unrelated reading/device friction |
| Evidence | Identify first response, assistance, item/context and accepted scoring source. Distinguish exposure, recognition, production and fresh independent evidence; missing and skipped are not success |
| Difficulty | Explain task demands/prerequisites, vocabulary/context burden and candidate challenge band. No empirical difficulty or learner level inferred from author intuition alone |
| Misconception | State the specific misunderstanding a distractor/error may suggest and plausible alternative explanations. One error does not diagnose a misconception or a “weak learner” |
| Feedback | Task-specific why/explanation and next action, kind and concise; no ego label, diagnosis, answer-only celebration or punitive pressure |
| Hint | Minimal helpful cue aligned with the error, distinguish from answer reveal; define where permitted. A cue revealing the answer cannot count as unaided evidence |
| Assistance level | Record hint/retry/worked example/replay conditions; preserve first response. Current bounded practice retry and no-hint/no-retry/no-skip Check behavior stay unchanged |
| Retrieval | Fresh opportunity to respond independently; do not count reading, watching, skip or repeated same-stem correction as fresh unaided recall |
| Transfer | Changed prompt/context preserving the objective and avoiding an identical answer cue. Specify near/broader scope; one MCQ does not prove broad real-world transfer |
| Delayed check | Candidate fresh/parallel item and a declared elapsed interval/condition; record prior exposure and missing observations. No universal optimal gap, five-minute efficacy or learning gain without valid evidence/design |
| Source/provenance | Creator, primary source/URL where applicable, license scope, attribution, capture date and reviewer. Unresolved ownership/license/accuracy blocks publication; generated material still needs review |
| Estimated time | Approximate metadata tied to content revision, later tested with real active/wall duration and context. “Khoảng 5 phút” where appropriate; no timer-based forced success or optimum claim |
| Accessibility | Scalable text, semantic prompt/options/feedback, logical traversal and non-color state; 48dp mobile targets, appropriate contrast, 200% text without critical loss; text alternatives. Manual TalkBack remains a real-human gate |
| Offline dependency | Identify required content/media, downloadable revision, storage/availability and fallback. Unavailable essential listening media makes the check unavailable; do not pretend audio or sync worked |
| Linguistic accuracy | Correct response, plausible non-ambiguous distractors, acceptable alternatives and locale/dialect/context notes; reject unsupported “only correct” wording |
| Review spacing | Explain due reasoning under a defined/versioned schedule and known-at evidence; schedule parameters remain hypotheses until validated |
| Challenge/prerequisite | Preserve the existing exact fixture predicate: two distinct unaided first responses including Check, same objective/band, allow only the bounded optional challenge preview. This is a **provisional heuristic**, not a scientifically frozen threshold; preview never unlocks or establishes mastery |
| Media | Licensed correct asset/version, legible/audible intended use, transcript/alternative, locale and availability/error handling. Playback UI is not evidence of physical playback |
| Age/culture and motivation | Audience-appropriate, non-stereotyping, autonomy-supportive copy; no medical/early-risk diagnosis, streak threat or manipulative reward loop |
| Revision integrity | Published content immutable/versioned; enrollment/attempt pin exact revisions; edits create new drafts. Preserve provenance and distinguish sample workflow from authoritative publishing |

## Worked review example — illustrative, unapproved content

Candidate draft “Chào hỏi và làm quen”: claim = recognize an appropriate greeting in a defined context. Task = a fresh short scenario with reviewed plausible response choices. Evidence = first unaided answer under declared conditions. Support = explain a contrast after an error, then retain any assisted retry separately. Retrieval = fresh scenario without the explanatory cue. Transfer = a different everyday context requiring the same distinction. Delayed check = reviewer-approved parallel prompt at a predeclared later occasion.

This example supports a narrow greeting-recognition claim, not fluent conversation, mastery or a final curriculum. Actual prompts/answers/parallel-item equivalence, license/media, objective band and elapsed interval require independent review before use in a learning study. A UI sample is not a reviewed lesson.

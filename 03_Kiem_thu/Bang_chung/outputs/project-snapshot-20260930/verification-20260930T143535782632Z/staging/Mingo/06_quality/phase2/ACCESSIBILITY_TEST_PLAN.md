# Accessibility / Responsive QA Plan

Priority baseline: WCAG 2.2 AA-oriented design review.

Mandatory checks: keyboard reachability/focus on staff; meaningful accessible names; semantic headings/landmarks; 48dp learner target sizing; contrast of actual token combinations; correctness not color-only; errors not color-only; 200% text zoom proxy; learner widths 360/390/480; staff 1024/1440; reduced motion; audio alternatives/context; no timer auto-cutoff of active response.

Any inaccessible critical action is P0/P1 depending on whether a viable alternative exists.

# Governance

Current project control plane: status, decisions, issues, change requests, backlog and roadmap.

Read `PROJECT_STATE.md` first. `PROJECT_PROGRESS_SNAPSHOT.md` is the latest handoff snapshot. `DECISION_REGISTER.md` records accepted decisions. `IMPLEMENTATION_ISSUES.md` records defects/gaps without silently altering the baseline. `CHANGE_REQUESTS.md` is required for approved foundational changes.

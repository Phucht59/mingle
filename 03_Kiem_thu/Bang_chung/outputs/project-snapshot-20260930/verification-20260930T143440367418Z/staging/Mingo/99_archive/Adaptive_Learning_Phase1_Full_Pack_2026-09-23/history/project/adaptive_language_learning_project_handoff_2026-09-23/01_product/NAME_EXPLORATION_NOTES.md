# Naming Exploration Notes

Historical naming discussion emphasized:

- short, memorable names;
- easy pronunciation;
- friendly learner-companion feel;
- names do not need literal semantics if they are memorable and brandable.

Names discussed included:

- BONGO
- Mingo
- PALS

`PALS` was noted positively because it conveys companionship. No final production name is recorded as frozen in the available project context.

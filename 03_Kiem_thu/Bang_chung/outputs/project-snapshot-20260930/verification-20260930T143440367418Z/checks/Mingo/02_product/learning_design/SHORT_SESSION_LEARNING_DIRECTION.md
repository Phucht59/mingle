# Short-Session Learning Direction

## Product hypothesis

Use approximately **5 minutes** as a default session-design anchor because the product aims to reduce activation friction and fit modern fragmented attention/content-consumption patterns.

## Critical distinction

The project discussion explicitly rejects the simplistic claim that “5 minutes is pedagogically optimal.” The real design question is:

> How can a learning session be short enough to match current consumption behavior while still producing meaningful, scientifically defensible learning?

## Design implications

A short session should still include a coherent learning loop, for example:

- a clear micro-goal;
- retrieval or active recall rather than pure passive consumption;
- a small amount of new material;
- immediate practice/feedback;
- a closure signal and next-step cue.

The final learning method should be evidence-driven rather than based only on founder intuition.

## Motivation layer

Streaks, rewards, and learner targets may support consistency, but they are engagement mechanics. They should not replace actual learning measurement.

## Validation requirement

Before locking the learning methodology, evaluate it against research on:

- retrieval practice;
- spacing;
- interleaving where appropriate;
- cognitive load;
- microlearning/short-session design;
- habit formation and return behavior;
- language-learning skill transfer;
- risks of shallow engagement from gamification.

This evidence work belongs in product/learning design and later Learning Intelligence work, not as an unverified architectural constant.

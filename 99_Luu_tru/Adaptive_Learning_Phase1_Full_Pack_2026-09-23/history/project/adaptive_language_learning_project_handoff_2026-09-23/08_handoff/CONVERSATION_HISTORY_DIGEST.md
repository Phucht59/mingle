# Project Conversation Digest

This digest preserves major themes visible in the shared project history.

## From original thesis understanding/presentation work

Prior conversations focused on understanding and presenting the KLTN pipeline, including:

- static / aggregate / temporal feature branches;
- temporal modeling concepts;
- CNN / BiLSTM processing;
- recommendation module explanation;
- UCI and OULAD research datasets;
- early-risk prediction framing;
- presentation/report corrections and diagrams.

These discussions belong to the **legacy research context**. They should inform historical understanding but do not override the V3.2 product architecture.

## Transition to productization

The project then shifted from thesis defense toward a real learning product. The retained direction includes:

- short, low-friction learning sessions;
- engagement mechanics such as streaks/rewards/targets;
- companion-like learner experience;
- public/open content sourcing where feasible;
- very small early pilot due resource limits;
- insistence that the learning method be grounded in research rather than founder preference.

## Architecture/product baseline

The architecture was iterated to V3.2, then frozen as the implementation source of truth. Phase 0 is complete; Phase 1 implementation foundation is active.

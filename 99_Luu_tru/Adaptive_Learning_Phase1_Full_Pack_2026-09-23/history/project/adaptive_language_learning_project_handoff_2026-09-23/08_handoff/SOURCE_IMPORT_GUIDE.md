# Source Import Guide

If continuing from this ZIP, create a `source_materials/` directory and import original artifacts using this priority:

1. V3.2 architecture/specification source files.
2. V3.2 contract-check and SQL-check code.
3. Database DDL/migrations.
4. Current application repository, if implementation has already started.
5. KLTN report and research code used only as historical reference.
6. Learning-method research/bibliography and the exact 18-question framework.
7. Diagrams, ERD, StarUML, slide sources, and other presentation artifacts.

## Conflict rule

When this reconstruction conflicts with an original V3.2 artifact, **the original V3.2 artifact wins** unless an approved later Change Request supersedes it.

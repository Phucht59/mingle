# Project Chronology

## Stage A — Original KLTN research system

The earlier work centered on educational data mining / early prediction / recommendation, using research datasets such as UCI and OULAD and discussing static, aggregate, and temporal modeling branches.

## Stage B — Thesis explanation and defense preparation

Project conversations focused on understanding preprocessing, temporal modeling, CNN/BiLSTM branches, recommendation logic, model evaluation, diagrams, report structure, and presentation scripts.

## Stage C — Productization decision

The project scope expanded beyond reproducing the thesis. The new goal became a practical language-learning and early-intervention platform with mobile learning, content, assessments, offline use, telemetry, analytics, intelligence, risk prediction, recommendations, staff/admin workflows, and production operations.

## Stage D — Architecture/contract stabilization

The product architecture was iterated to V3.2. The recorded state is 115 contract checks and 22 SQL checks passing, with V3.2 frozen as the implementation source of truth. Phase 0 was then considered complete.

## Stage E — Product/learning-method exploration

The learner experience discussion introduced short (~5 minute) sessions, streaks/rewards/targets, a study-companion identity, public/open source content constraints, and a small pilot. Importantly, the user required the learning method to be justified by research and current content-consumption behavior rather than personal intuition.

## Stage F — Current state

Phase 1, Implementation Foundation / Product Build Kickoff, is active. The project should now build the runnable foundation under V3.2 rather than reopening broad architecture design.

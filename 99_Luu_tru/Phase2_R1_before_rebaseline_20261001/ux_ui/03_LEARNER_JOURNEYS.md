# Learner Journeys

## J-L01 — First use without forced placement

Launch → Welcome → Goal (select or skip) → Placement offer → Skip placement → Home with provisional/missing-evidence state → Start finite cycle → Summary → Done for now.

Success: learner can begin without long gate, sees honest uncertainty, and no CEFR certification/mastery claim is made.

## J-L02 — First use with placement

Welcome → optional Goal → Placement → short Vocabulary/Grammar/Listening items → provisional result → Home. Missing/unsupported domain remains “not enough evidence,” not a fabricated score.

## J-L03 — Returning learner / due review

Home shows next action + factual reason (`Due for review`) → Cycle Intro → at most one justified due/prerequisite insertion according to current hypothesis → focused content → Check → Summary.

## J-L04 — Wrong → feedback → retry

Retrieve item → wrong first response → explanatory feedback → optional practice retry → correct retry → continue. UI congratulates the retry without implying the first response changed. Evidence semantics remain first wrong + eventual assisted/correct practice.

## J-L05 — Hint-assisted response

Practice item → learner requests hint → hint shown → answer → feedback identifies support context. This path never qualifies as unaided evidence in UX language.

## J-L06 — Skip

Practice item → “Skip for now” → non-shaming confirmation → continue with no completion/mastery/reward claim. Repeated skip support is a versioned later policy, not diagnosis.

## J-L07 — Independent Check

Check Intro explains context → Check item has no pre-submit hint → submit → result/feedback → cycle summary. Listening Check may show offered play policy, but UI never says client playback count proves physical listens.

## J-L08 — Course map and locked preview

Course → locked objective → reason/prerequisite → preview → back. Preview creates no progress or unlock. Eligible objective can start/resume learning.

## J-L09 — Offline learning and later sync

Connectivity loss → visible offline banner → learner continues only downloaded/eligible work → business action is “saved on this device / waiting to sync” → connection returns → syncing → canonical accepted/synced state. Sync failure offers safe retry, not manual duplicate submit.

## J-L10 — Recommendation unavailable

Home recommendation service unavailable/disabled → ordinary eligible curriculum or due-review options remain → learner can start cycle. If no valid content exists, show honest content gap/nothing-due state.

## J-L11 — Evidence/profile

Profile → evidence cards show observations, “building” or “needs more evidence,” and known uncertainty → optional related review. Streak/target are separated from learning evidence.

## J-L12 — Interrupted cycle

Learner exits or app closes → later Learn/Home offers Resume → state is restored without duplicate submit. If pinned content becomes unusable, show safe refresh/resolution rather than silently rewriting history.


## J-L13 — Required response validation

Review/Transfer/Check Submit cannot advance while no answer is selected. Where Skip is allowed it is a separate explicit path. A Check with no response cannot reach Cycle Complete.

## J-L14 — Representative Grammar objective

Learn short `am/is/are` scaffold → Retrieve `He ___ my friend` with optional practice hint → Transfer to `They are classmates` → independent Check `I ___ ready`. Assistance persists as assisted evidence; Check has no pre-submit hint.

## J-L15 — Representative Listening objective

Practice exposes AudioControl and flexible replay; independent Listening Check exposes an offered-play limit (current hypothesis: two). Playback request count is telemetry only. If required media is unavailable offline, Check blocks safely instead of fabricating completion.

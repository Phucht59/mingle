# Product language glossary

Internal terms stay in specs, never as the main learner task. English content answers are intentional.

| Internal | User-facing | Meaning preserved |
|---|---|---|
| Review | Nhớ lại một chút | Old-item review, distinct evidence |
| Learn | Một cách chào mới | Teaching/explanation; not assessment |
| Retrieve | Thử tự nhớ | Practice; hint/retry marked assisted |
| Transfer | Dùng trong tình huống mới | Distinct context, same objective |
| Check | Thử không cần gợi ý | No hint/retry; first response retained |
| mastery | Đã vững / cần thêm bằng chứng | Only with sufficient authoritative evidence, no arbitrary percent |
| risk | Dự đoán cần hỗ trợ | Staff only in a future layer; different from mastery |
| local_queued | Đã lưu trên máy, đang chờ gửi | Never server success |
| syncing | Đang gửi / chờ xác nhận | Connectivity is not acknowledgement |
| synced | Đã được hệ thống xác nhận | Only actual receipt; fixture explicitly marked mẫu |
| partial | Một phần đã gửi, phần còn lại đang chờ | Show per-item state |
| canonical refresh | Bài cần tải lại đúng phiên bản | Keep pinned old response separate |
| worker unavailable | Thao tác đang chờ xử lý | Do not announce publication/progress success |
| license pending | Cần kiểm tra nguồn và giấy phép | Publishing blocker |
| published immutable | Bản đã xuất bản chỉ để đọc | Create a separate draft to edit |
| insufficient evidence | Cần thêm một chút thực hành | No deficit/risk conclusion |
| reauth | Cần đăng nhập lại | Design-only until Phase3 approved |

Use sentence case, concrete verbs, calm recovery. Do not use precision-looking skill percentages, “tối ưu bởi AI”, command/telemetry/availability-time jargon or success without acknowledgement. Future references disclose their scope at the boundary.

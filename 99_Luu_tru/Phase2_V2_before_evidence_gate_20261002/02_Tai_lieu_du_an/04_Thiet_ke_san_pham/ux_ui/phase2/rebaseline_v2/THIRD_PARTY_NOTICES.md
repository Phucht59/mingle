# Third party assets and playback

Inter: Google Fonts official ofl/inter, OFL1.1 bundled in assets/fonts/OFL.txt. Flutter collects dependency licenses in its generated NOTICES.

Audio: “Hello”, Dvortygirl,13August2005, unmodified pronunciation sample, public-domain dedication. [Original source](https://commons.wikimedia.org/wiki/File:En-us-hello.ogg). Source SHA1 matches the author asset. Local playback uses pinned audioplayers6.5.1, a UI media adapter with no recording/scoring/telemetry. Platform dependency versions are locked in pubspec.lock. [Maintainer guide](https://github.com/bluefireteam/audioplayers/blob/main/getting_started.md?plain=1).
